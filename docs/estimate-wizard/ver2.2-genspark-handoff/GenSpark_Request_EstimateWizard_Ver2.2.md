## 0. 用語・全体ルール（binding）

- **APU**：アプリを使用するディテーラー（オペレーター）。**顧客**：APU の客（車両オーナー）。
- **記入順＝入力優先順位**。`*`＝入力必須（未入力は**色付けハイライト**、入力完了で通常＝白へ戻す。色は Amber）。`**`＝注意・補足。
- **UI3 以降：プルダウン（`<select>`）禁止。全選択は押しボタン式**（何が選択されているか開かず一目で分かる）。
- **スワイプでのページ移動は廃止。Back/Next ボタンのみ**（PC/タブレット/スマホ共通）。
- **ダークモードのみ**（ライトモード不要）。3デバイス（PC/タブレット/スマホ）納品。
- **committing 操作（選択・入力・追加・保存等）を増やさない**（遷移/確認の追加で操作数を増やさない）。
- **価格・メニュー・係数・部位・クーポン等は店舗設定 / pricing データ由来**。UI にハードコードしない（動的リスト前提）。

## 1. OCR 入力（全デバイス統一・既存パイプライン）

**車検証OCRボタン押下で、3つの入力方式を明示表示**（すべて既存 OCR パイプラインへ）：
1. **写真を撮影**（カメラ・`capture="environment"`）
2. **写真から読み込み**（画像：JPEG/PNG/WebP/HEIC）
3. **PDF読み込み**（`application/pdf`）

- フロー不変：**入力ソース → OCR解析（既存）→ フォーム反映 → オペレーター修正 → 保存**。
- OCR プロンプト/モデルは変更しない。デバイスごとに別ロジックを作らない。読み取り後は全項目編集可。

## 2. Estimate Wizard — 7スクリーン（順序固定・不変）

`1 顧客登録 → 2 車両登録 → 3 作業内容選択 → 4 見積 → 5 値引き/クーポン → 6 備考 → 7 確認`

### Screen 1 — 顧客登録
- **登録方式** `*`（押しボタン・**デフォルト＝手入力（新規顧客登録）**、いつでも切替可）：
  - `手入力（新規顧客登録）`（既定）／`車検証OCR`（§1）／`既存顧客を検索`（**検索押下時のみ**モーダルを開く：名前(漢字＋フリガナ)・住所(大まか可)・電話・ナンバー下4桁）
- 入力（順）：`お客様名` `*`（**フリガナ自動生成**）／`郵便番号`（**郵便番号⇄住所 自動**）／`住所`／`電話番号`／`LINE ID`（手入力 or **QR読み取り**）
  - `**` **LINE QR は、APU が店舗設定で LINE Business を登録した場合のみ表示**。
- **業者ボタン / 掛売りボタン（独立2ボタン）**：`業者`→**値引率（%）**入力／`掛売り`→**締め日・支払条件**入力（締め支払ルールに従い請求集計）。
- `**` 法人の場合は信販会社かを精査し、信販会社なら**使用者を顧客として登録**（内部処理・**信販専用UIは作らない**）。信販以外は通常顧客。
- `**` SNS 連携は将来（LINE/WhatsApp/SMS/Instagram/X）。**今回のSNS入力は LINE ID のみ**（他SNS ID欄は将来）。
- `**` OCR AI は既定で運営 API、顧客が GPT API 登録で切替（常に GPT-mini）。将来：管理者がモデル変更可・失敗継続で管理者へ警告（backend/将来）。

### Screen 2 — 車両登録
- 入力方式：`車検証OCR`（§1）／`手入力`。
- 入力（順）：`ナンバープレート` `*`（例 滋賀 330 に 1234）／`メーカー` `*`（車検証＝社名）／`車名` `*`（**車検証取得不可・手入力必須**）／`型式`／`車体番号`／`初年度登録年月`／`登録年月日`／`ボディカラー`／`車検満了年月日`。
- **ボディサイズ（3M計算・7ボタン）**：`SS/S/M/ML/L/LL/XL` を押しボタンで配置。車検証の長さ・幅・高さから3M計算し、**該当サイズを推奨として色付け（default 表示）**。**ただし推奨のみ・最終決定はAPU**（自動確定しない・修正可）。
- フロー：OCR → フォーム入力 → 3M計算 → 推奨サイズ提示 → 修正可。

### Screen 3 — 作業内容選択（複数選択・押しボタン）
- カテゴリ：`コーティング` / `PPF` / `PPF部分施工` / `ウィンドウフィルム` / `ボディ定期メンテナンス` / `洗車` / `ルームクリーニング` / `その他の作業`。
- `**` 選択したカテゴリのみを Screen4 に表示。
- `**` **【要 Architect 確認】** Ver2.2 本文は Screen3 に「PPF部分施工」を独立カテゴリとして列挙。一方 Screen4 では「コーティング＋PPF 選択時に部分施工PPFを表示」とも規定。**PPF部分施工を独立カテゴリにするか／Screen4分岐にするか**は公式 Spec で確定要（本書は暫定的に両立表記）。

### Screen 4 — 見積（選択カテゴリのみ表示・全ボタン式）
共通：**プルダウン不可**。選択は押しボタン。前段を決めてから次段（グレーアウトで不可を明示）。**スワイプ廃止・Back/Next のみ**。

**コーティング**（ショップランク別・レイヤー先行）
- 1層目の剤に応じて2/3層目の選択肢が変化。単層選択時は2/3層ボタンをグレーアウト。
- **GYEONショップ**：単層 `Q² ONE EVO`／`Q² CANCOAT EVO`。2層：ONE→(ONE or CANCOAT)。**PPF・フィルムのボタンをグレーアウト**。
- **GYEONディテーラー**：単層 ONE/PURE/MOHS/SYNCRO/MATTE。2層：ONE→(ONE/CANCOAT)・PURE→(PURE/CANCOAT)・MOHS→(MOHS/CANCOAT)・MATTE→(MATTE)・SYNCRO→(既定2層・MOHSのみ追加可)。3層：ONE/PURE/MOHS→(CANCOAT)。
- **GYEONサーティファイドディテーラー**：単層 ＋ `INFINITE BASE TYPE 1/2`。2層：上記＋INFINITE BASE 1→(BASE1 / INFINITE TOPCOAT 1 or 2)・BASE 2→(BASE2 / TOPCOAT 1 or 2)。3層：上記＋INFINITE BASE 1/2→(TOPCOAT 1 or 2)。
- `**` **GYEON PPFインストーラー**の場合は**コーティングボタンをグレーアウト**。
- `**` PPF+コーティング選択時はコーティング費用が減額される場合あり（店舗設定の**減額補正**を適用）。
- `**` **GYEON には PPF 専用コーティング材があり、PPF にコーティング施工金額を装備**。

**PPF**（種類選択→係数）
- 種類：グロス・プロテクション `PPF PROTECT+`/`PPF ENHANCE`/`PPF HYBRID`／マット・ステルス `PPF MATTE`／カラー＆カスタム `PPF BLACK`/`TINT`/`PPF CARBON`/`PPF COLOR LINE`。
- フロー：PPF選択 → 施工するPPF種類選択 → **店舗設定の施工係数を掛ける** → 見積明細。
- **施工エリア/ケース**：フル／部分（部位別・**店舗定義で拡張可能な部位リスト**）／**サンルーフ**／**フロントガラス（Windshield）**／**室内PPF施工（Interior）**。
  - **室内PPF施工**：`金額のみ入力＋施工箇所を手入力`（行追加可）。例：室内PPF施工 ￥46,000（ナビゲーション・メーターパネル・ウッドパネル部）。
- `**` GYEON 以外の PPF を施工する APU も想定（店舗設定で種類拡張）。
- `**`（将来）発注/在庫システム実装後、3M計算から使用量推定＋在庫DB仕入価格で**原価計算**（今回は実装しない）。

**ウィンドウフィルム**（部位→フィルム種類）
- 施工部位ボタン：`フロントガラス`/`フロントドアガラス`/`リアドアガラス`/`三角窓`/`クオーターガラス`/`リアガラス（リアハッチ）`/`サンルーフ`。
- `**` 部位ごとにフィルム種類が異なる場合あり。**フィルムのメーカー/種類は店舗設定で APU が設定**。

**洗車 / ボディ定期メンテナンス / ルームクリーニング**（各店舗メニュー）
- 各店舗が設定したメニューを押しボタン表示。**店舗設定でメニュー名＋金額＋想定必要時間（分）を登録**（カレンダー実装時に所要時間として引用）。**項目は無制限に追加可能**。

**その他の作業**
- 自由に手入力できる欄。**行追加で何項目でも追加可能**。

**店舗別オプション（グローバル）**
- 追加サービスオプションとして配置（例：鉄粉除去/ハードポリッシュ/傷補修/ヘッドライトリペア/タッチペン）。**店舗設定で設定したもののみ表示**。デフォルト例をプリセット。動的（改名/追加/削除/価格変更可）。

### Screen 5 — 値引き / クーポン
- クーポン：**押しボタン・複数選択**。内容は店舗設定で登録。
- 値引き：**金額 または ％**（`**` %入力時は現小計から円換算し既存値引き計算へ適用）。

### Screen 6 — 備考・メモ
- `備考`（見積内に表示）／`社内メモ`（社内用記録）。明確に分離。

### Screen 7 — 確認
- ボタン：`修正` / `キャンセル` / `保存` / `PDF作成` / `LINE`（送信/文章コピー） / `予約日を決めてカレンダー登録` / `請求書` / `納品書` / `納品請求書`。
- `**` **キャンセル以外は自動保存**。各ナビゲーションは自動保存後に該当モジュールへ遷移。
- `**` `LINE`：Business 設定済＝「LINE送信」／未設定＝「LINE文章コピー」（どちらも挨拶文＋見積内容を自動生成。挨拶文テンプレは店舗設定で編集可）。
- `**` 既存見積の修正時は登録済み施工内容・価格・数量・オプションを初期表示。`修正`で該当STEPへ戻り編集（入力済みデータ保持）。
- `**` **全ページに Back/Next**。上部にステップ・ナビ（顧客→車両→…現在地表示・任意ジャンプ可）。
- `**` 保証書印刷（コーティング/PPF）は施工完了 or 納品書発行時に出力可能（見積段階では非表示）。
- `**` 請求書/納品書/納品請求書 押下で請求書欄へ移行。

## 3. Store Settings（GenSpark は設定画面ではなく見積UIのみ／依存の明示）
見積UIは以下の店舗設定データに依存（値はハードコードしない）：**ショップランク**（shop/detailer/certified/**PPFインストーラー**）／コーティング価格・レイヤー・PPF専用コーティング／PPF（種類・係数・部位マスタ・サンルーフ/ガラス/室内・PPF+コーティング減額）／ウィンドウ（部位×フィルム種別×価格）／洗車・メンテ・ルーム（**メニュー名＋金額＋想定必要時間(分)**・無制限）／店舗オプション／クーポン／LINE挨拶文テンプレ。

## 4. レスポンシブ（3デバイス・ダークのみ・スワイプ無）
- ブレークポイント：Mobile `<768` / Tablet `768–1023` / Desktop `1024+`。
- **Desktop**：2カラム（左＝ステップ内容／右＝sticky 合計＋Back/Next）、上部横型ステッパー、Screen4 は縦タブ。
- **Tablet**：単カラム＋下部固定合計バー＋Back/Next、Screen4 は縦タブ/セグメント。
- **Smartphone**：単カラム＋コンパクトステッパー（タップでボトムシート一覧）＋下部固定バー＋Back/Next、Screen4 はカテゴリカード→詳細。OCR/QR はフルスクリーン級オーバーレイ。
- **スワイプ移動は全デバイスで不可（Back/Next のみ）**。広い要素は各自 `overflow-x:auto`（本文横スクロール禁止）。

## 5. デザイントークン（ダーク・厳守）
背景 `#0f172a`／カード `#1e293b`（rounded-xl/shadow-lg/p-5）／入力 `#0f172a`＋`border-slate-700`、focus `#1d4ed8`／プライマリ `#1d4ed8`(hover `#1e40af`)／選択ON `bg-blue-950/40 border-[#1d4ed8]`／本文 `text-slate-100/200`・ラベル `text-slate-400`／**必須未入力 Amber `#fbbf24`（完了で通常へ）**／成功 `#22c55e`／エラー `text-red-400`。タイポは sans（日本語優先）、入力 `text-base`(モバイル)/`sm:text-sm`、金額 `tabular-nums`。アニメは控えめ・高速（150–200ms）・`prefers-reduced-motion` 尊重。タップ 48×48px。**グレーアウト＝disabled を明示**。
