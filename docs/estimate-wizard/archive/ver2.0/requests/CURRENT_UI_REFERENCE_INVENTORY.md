## Step 1 — 顧客（セクション見出し: `顧客`）

**モード切替チップ（2）**: `既存顧客を選択` / `新規顧客を作成`

### 既存選択モード
- ラベル `顧客を選択` → セレクト（先頭 option `顧客を選択...`）

### 新規作成モード（入力順・実ラベル）
1. `お客様名 / 会社名` **`*`** — text — placeholder `山田太郎 / 株式会社〇〇` — 補助 `個人名・法人名をそのまま1項目で入力（分割しません）`
2. `電話番号` — tel — placeholder `090-0000-0000`
3. `メール` — email
4. `郵便番号` — text — placeholder `000-0000`
5. `LINE ID` — text
6. `住所` — text（2カラム幅） — placeholder `都道府県・市区町村・番地`
7. チェックボックス `業者（法人）`
   - ON時のみ表示（枠内・2カラム）:
     - `掛け率（%）` — number(0–100)
     - チェックボックス `売掛（AR）許可`
     - `締め日` — number(1–31) — placeholder `例: 20`
     - `支払日` — number(1–31) — placeholder `例: 末=31`
- ボタン: `この顧客を登録`（登録中 `登録中...`、`氏名` 未入力で disabled）

> ※ **LINE QR**（友だち追加QR）は依頼書 §6 の要件。GenSpark はオーバーレイ表示としてデザイン（現行コードは LINE ID テキスト入力を保持）。

## 定数リファレンス

- **CATEGORY_LABEL**: `coating→コーティング / ppf→PPF / window→ウィンドウ / interior→インテリア / glass→ガラス / other→その他 / maintenance→メンテナンス / carwash→洗車 / roomclean→ルームクリーニング`
- **PPF 数量入力必須 部位**: `sp-step`, `sp-door-cup`（他は数量1固定 `×1`）
- **ボディサイズ**: `catalog.bodySizes`（既定 `SS / S / M / ML / L / LL / XL`）

---

## UI に影響する保持必須の挙動（機能欠落防止）

1. `ウィンドウフィルム` `ルームクリーニング` は**単一インスタンス**（再追加で重複せず更新）。
2. `ボディ定期メンテナンス` `メンテナンス洗車` は**新規作成時のみ表示**（編集時は非表示、既存明細行は明細テーブルに残る）。
3. 明細行削除は**確認なし即時**（→ ウィザードでも確認ダイアログを足さない。誤タップ対策は undo トースト等で）。
4. `保存` は `catalogReady` 完了まで disabled。
5. `PDF作成` `LINE画面へ` `予約日を決めてカレンダー登録` は**保存済みが前提**（未保存で disabled、予約は保存を自動実行してから遷移）。
