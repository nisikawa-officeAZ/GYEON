Tablet UI プレビュー

DealerOS GYEON 見積ウィザードのタブレット向け UI を 3 パターン設計しました。 iPad Pro 11" (834×1194) を主対象に、施工ブースでの立ち作業・顧客への画面共有・ タッチ操作最適化を意識しています。デザインは PC 版と同じ言語体系を維持。

パターン一覧
A. 横向き最適 Landscape

iPad Pro 11" 横向き (1194×834) を主対象。PC 版に最も近い体験で、 カウンター受付や資料参照時の使用に最適。

サイドバー 240px 常時表示
フルステッパー 7 ノード
Screen 4: 左サイド縦タブ
右 Sticky Total 220px
OCR/QR: 右半分スライドパネル
開く →
B. 縦向き最適 Portrait

iPad Pro 11" 縦向き (834×1194) を主対象。片手でボディを支えつつ もう片手で操作するシーンや、顧客と対面で画面を見せながらの説明に最適。

サイドバー非表示・単カラム主体
フルステッパー (縦画面でも余裕)
Screen 4: 上部 SegmentedControl
右 Sticky Total 200px
OCR/QR: 右半分スライドパネル
開く →
C. 両対応 Adaptive 推奨

向きに応じて Landscape / Portrait を自動切替。iPad を持ち替えても 違和感なく操作可能。実運用ではこのパターンを推奨します。

Landscape 時: サイドバー + 縦タブ
Portrait 時: 単カラム + SegmentedControl
切替は CSS のみ (状態保持)
右 Sticky Total は両向きで維持
OCR/QR: 右半分スライドパネル
