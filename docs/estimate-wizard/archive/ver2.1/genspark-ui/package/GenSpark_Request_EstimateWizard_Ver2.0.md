- **muscle memory 保持**。新規/編集で見た目を変えない。

- **自由ナビゲーション**: 全ステップいつでも 1 タップジャンプ可。
- **自動保存**: キャンセル以外のアクションで自動保存。
- **ダークモードのみ**、ライトモード不作成。
- **タップ 48×48px 最小**。
